Why the total stays constant

First, the linear momentum. Internal forces cancel in pairs (Newton's third law), so

dP/dt = Σi Fi = Σi,j Fij = 0

The cyan arrow at the center of mass is P = M Vcm. It keeps a fixed length and direction while the bodies swirl.

Now take any point O that is fixed in space. Differentiate the total angular momentum about it:

dL/dt = Σ vi × mivi + Σ (ri − rO) × Fi

The first sum is zero because a vector crossed with itself vanishes. With only internal forces, Fi = Σj≠i Fij, and Newton's third law pairs them up:

Σi rO × Fi = rO × Σi,j Fij = 0
Σi ri × Fi = Σi<j (ri − rj) × Fij = 0

The last sum vanishes because gravity is central: Fij points along ri − rj. So dL/dt = 0 for every fixed O. Moving O changes the value by −rO × P, which is also constant because P is conserved.

Turn on the external field and the torque no longer cancels:

dL/dt = Σ (ri − rO) × mig = M(Rcm − rO) × g

The field also gives a net force, dP/dt = Mg, so the P arrow tips downward and grows.

The simulation uses a leapfrog integrator. Each step keeps Σ ri × Fi = 0 exactly, so L holds to rounding error (about 10−15). The energy wobbles slightly because the integrator only approximates it.
